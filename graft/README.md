# Graft — Code Connection Map

โฟลเดอร์นี้เป็นแผนที่เชื่อม requirement → data → backend → UI → tests

- `CODE_MAP.md` ระบุตำแหน่งความรับผิดชอบของโค้ด
- `DATA_FLOWS.md` แสดงเส้นทางข้อมูลหลัก
- `CHANGE_CHECKLIST.md` ใช้ทุกครั้งที่แก้ระบบ

เริ่มอ่านจาก `SOT.md` แล้วใช้แผนที่นี้ก่อนแก้ behavior เพื่อไม่ให้ logic เดียวกระจายซ้ำหลายจุด

`docs/V1_ARCHITECTURE_AND_DEPLOYMENT.md` is the v1 cross-system deployment map; it links source telemetry, OPERATION outputs, Dashboard metadata and technician workflow without changing runtime ownership.
